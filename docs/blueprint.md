# **App Name**: CipherSphere

## Core Features:

- Mock Authentication: Simulate user login with email/password and store session data in LocalStorage.
- Text Messaging: Send and receive text messages within the chat interface, saved locally.
- Image Sharing: Upload images from device and capture from camera using MediaDevices API.
- Audio Recording: Record voice notes using MediaRecorder API and play them back.
- Message Persistence: Store messages in LocalStorage to persist them across sessions.
- AI Assistant: Use Google Gemini API to create an AI assistant, which takes user input and uses it as a tool when considering whether to give information as output (API key will be a placeholder).
- Project Export: Export the complete project source code as a .zip file using JSZip library.

## Style Guidelines:

- Primary color: Indigo-600 (#6366F1) for interactive elements and highlights.
- Background color: Slate-950 (#020617), a near-black to set a professional cyberpunk mood.
- Accent color: Violet-500 (#8B5CF6) to complement indigo and enhance the cyberpunk feel.
- Body and headline font: 'Inter', a sans-serif for a modern, objective feel.
- Use @heroicons/react for consistent and modern icon styling.
- Sidebar navigation on the left, chat area in the center, and floating action buttons for key functions. All elements should incorporate rounded corners (rounded-3xl) and glassmorphism (backdrop-blur).
- Incorporate smooth transitions throughout the application to enhance the user experience.
